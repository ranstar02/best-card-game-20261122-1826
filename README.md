**Lantern Pact — Duel of the Ember Court**: an original 1v1 trick-taking card duel against the Warden of the Last Lantern. Both duelists start at 20 HP; each trick, the higher card wins and burns the loser for the difference. A rotating Court suit gains +2, hands refill to five cards, and three once-a-game Pacts (Mirror, Ember, Veil) turn a losing trick around. Suits are told apart by colour and shape — Flame, Tide, Leaf, Stone — on a candle-lit canvas table with synthesised WebAudio sound, no libraries and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a card to play it (keys 1–5 work too), click a Pact token to spend it, Enter starts, R restarts, M mutes.
